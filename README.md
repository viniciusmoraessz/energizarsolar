# NovaEco Solar

Landing page em Next.js 14, TypeScript e Tailwind CSS para a NovaEco Solar.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy na Vercel

Na Vercel, importe este repositório e use as configurações padrão para Next.js:

- Framework: Next.js
- Build command: `npm run build`
- Install command: `npm install`
- Output: gerenciado automaticamente pela Vercel
